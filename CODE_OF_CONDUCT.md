# Código de conducta

Esperamos una colaboración respetuosa, técnica y centrada en evidencia.

No se toleran acoso, discriminación, amenazas, publicación de información privada, atribuciones
personales no verificadas ni uso del proyecto para hostigar a profesionales o pacientes. Los
ejemplos, reportes y pruebas deben usar datos sintéticos.

Los mantenedores pueden editar o retirar contenido, rechazar contribuciones o limitar la
participación cuando sea necesario para proteger a la comunidad o a terceros. Los incidentes de
conducta pueden reportarse de forma privada mediante el canal indicado en
[`SECURITY.md`](./SECURITY.md).
